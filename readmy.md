# opcua-ek270

Промышленный шлюз (Gateway) на Python для интеграции корректора объема газа **Elster EK270** в современные системы мониторинга.

## 🚀 Описание проекта
Сервис предназначен для автоматизированного сбора данных с приборов учета газа по протоколу **Modbus RTU** и  доступа к ним через веб-интерфейс (**REST API**). Проект упакован в Docker-контейнер, что позволяет развернуть его на любом промышленном ПК или сервере.

## 🛠 Технологический стек
- **Backend**: Python 3.9 (FastAPI, Uvicorn)
- **Протокол**: Pymodbus (Modbus RTU)
- **Среда**: Docker / Docker Compose

## 📋 Основные возможности
- **Чтение данных**: Плотность, температура, давление и другие параметры.
- **Гибкая настройка**: Карта регистров и параметры связи вынесены в отдельный файл `settings.py`.
- **Автодиагностика**: Статус подключения к прибору отображается в API.
- **Swagger UI**: Интерактивная документация для тестирования запросов "из коробки".

## 📦 Установка и запуск
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd opcua-ek270
   ```
2. Подключите корректор через преобразователь RS-232.
3. Настройк корректора ЕК270: 
   Интерфейс
   - РИнт2 = Modbus
   - Инт2  = 8n1
   - СИнт2 = 9600
   - ТИнт2 = RS232
   - ШинИ2 = Шина.Выкл   
4. Запустите сервис:
   ```bash
   docker-compose up -d --build
   ```

## 📡 API Эндпоинты
- `GET /api/data` — получить актуальные технологические параметры (JSON).
- `GET /docs` — интерактивная документация Swagger для проверки связи.
